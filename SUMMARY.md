## 🚀 Untuk Deploy Nanti (3 Steps Simple)

### Step 1: Push ke GitHub
```bash
cd xelta-website
git add .
git commit -m "XELTA website ready to deploy"
git push origin main
```

### Step 2: Connect ke Vercel
- Buka vercel.com
- Login dengan GitHub
- Click "New Project"
- Pilih repository `xelta-website`
- Click "Deploy"

### Step 3: Done! 
Website live! 🎉
